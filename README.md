# Learning Python

A personal repository for learning Python from scratch, organized by chapter with hands-on exercises and concept examples.

## 📁 Project Structure

```
Learning Python/
├── Chapter 1/          # Python basics and introductory problems
│   ├── Problem 1.py    # Multi-line string using triple quotes
│   ├── Problem 2.py    # Text-to-speech using pyttsx3
│   └── Problem 3.py    # Listing directory contents using os module
│
└── Chapter 2/          # Core Python concepts
    ├── 01_variables.py # Variables and basic arithmetic
    ├── 02_datatypes.py # Python data types (int, float, str, bool, None)
    ├── 03_operators.py # Arithmetic, assignment, comparison, and logical operators
    └── 04_type.py      # type() function and type conversion
```

## 📚 Topics Covered

### Chapter 1 – Getting Started
- Printing multi-line strings with triple quotes (`"""`)
- Text-to-speech with the `pyttsx3` library
- Working with the `os` module to list files in a directory

### Chapter 2 – Core Concepts
- **Variables** – declaring and using variables
- **Data Types** – `int`, `float`, `str`, `bool`, `None`
- **Operators** – arithmetic, assignment, comparison (`==`, `!=`, `>=`), and logical (`and`, `or`)
- **Type Checking & Conversion** – `type()` function and casting (e.g., `float()`)

## 🛠️ Requirements

- Python 3.x
- `pyttsx3` (for Problem 2) — install via:
  ```bash
  pip install pyttsx3
  ```
