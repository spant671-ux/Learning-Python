## 🚀 Getting Started

Make sure you have **Python 3** installed. Check your installation:

```bash
python --version
```

### Quick Examples:
Run any file directly from the root directory:

```bash
# Comments & Variables
python "01basics/01comms-and-var.py"

# Data Types & Conversion
python "01basics/02datatypes.py"

# Strings & Slicing
python "01basics/03strings.py"

# Input & Output
python "01basics/04in-out.py"

# Operators
python "01basics/05operators.py"

# Conditionals & Control Flow
python "02control-flow/if-else.py"

# Loops & Iterations
python "03iterations/for-loop.py"
python "03iterations/while-loop.py"

# Functions
python "04functions/function.py"

# Data Structures - Lists
python "05data-structures/lists.py"

# Exception Handling
python "06exception-handling/new.py"
```
